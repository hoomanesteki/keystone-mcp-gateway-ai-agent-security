## Found

On macOS, a background process can flag dot-directories such as `.venv` as hidden, and Python
skips hidden `.pth` files, so `import keystone` fails after `uv sync`. Setting
`UV_PROJECT_ENVIRONMENT` to a path outside the repo avoids it (see docs/runbook.md).

`SessionState.call_count` was not incremented by any slot until KS-704, so `context.call_count` was 0
for every call. The flags slot now counts each call that returned without an error (the metering
slot of Phase 8 adds the spend). The session flags and the taint are recorded since KS-704 as well.

A session was saved whole when a call ended (`RedisSessionStore.save` was a `SET` of the
document), and a call can last up to 300 seconds in an approval hold, so a long call that ended
after another call changed the session's flags or taint wrote its older copy back over them.
Fixed by KS-791 (ADR-0015): a session changes by merging.
